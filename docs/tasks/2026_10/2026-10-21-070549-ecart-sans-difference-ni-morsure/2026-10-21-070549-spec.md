# Spec — un écart sans différence garde le repli « Aucune action dérivée »

> V0.1 — 2026-10-21, nom `2026-10-21-070549` ; le dossier est né à **07:05:49** (`stat -c %w`), dans la
> même seconde que le nom. Demande directe de l'opérateur : « Ajoute un contrôle de banc pour un écart
> sans différence ni morsure, afin de vérifier que le rapport conserve le repli “Aucune action
> dérivée”. » Suite des contrôles **187** et **188**.

## 1. Le trou de couverture

`sectionPistes` porte un repli quand aucune piste n'est dérivable :
`Aucune action dérivée ; relire le reçu et le produit.` Aucun contrôle ne le fixe. Le 187 couvre une
différence sans morsure, le 188 une différence avec morsure ; un `ecart` sans différence, sans morsure,
sans limite et sans lecture hors dossier n'est mesuré nulle part.

## 2. La règle éprouvée

Pour un reçu `ecart` dont :

- `falsificateurs` est vide, ou ne porte que des valeurs muettes ;
- `limites` est vide ;
- `falsificateurs.lecture_hors_dossier` est une liste vide ;
- les pièces `output.json`, `trace/echange.jsonl`, `gate.json` et `faits.json` sont présentes ;
- `output.difference` est vide ou absente ;

le §7 doit contenir exactement le repli `Aucune action dérivée ; relire le reçu et le produit.`, ne doit
pas nommer `Relire l'écart nommé par le juge`, et le §5 ne doit pas afficher « L'écart nommé par le
juge ».

Aucun code du générateur ne change : le repli existe déjà ; le contrôle le fixe.

## 3. Le contrôle 189

Un contrôle **189** part d'une copie du run `conforme` de 179, puis :

- passe le reçu et l'output en `ecart` ;
- met `limites` à `[]` et `falsificateurs.lecture_hors_dossier` à `[]` dans le reçu ;
- vide `output.difference` ;
- exécute `rapport` sur cette copie.

Il exige le repli exact, l'absence des deux textes de différence, et des empreintes de `receipt.json`
et `output.json` identiques avant et après. Il ne crée aucun run et n'écrit rien dans le dépôt.
Le contrôle de mutation enlève le repli de `sectionPistes` et exige que seul le 189 tombe.

## 4. Ce qui ne change pas

`run.mjs`, `rapport.mjs`, `receipt.json`, `output.json`, l'orchestrateur, les verdicts et les contrôles
179 à 188. Le compte du banc passe de 188 à 189.

## 5. Limites

Le contrôle 189 part d'une copie synthétique d'un run `conforme` et ne prouve ni l'origine de l'écart
ni la justesse du produit. Il ne remplace pas un run réel qui porterait ces trois absences.

## 6. Critère de sortie

`bash docs/device/harness/banc-harnais.sh` => **189/189 PASS**, `exit 0` ; le 189 tombe seul si le repli
est retiré du générateur ; `bash -n` sur le banc et `git diff --check` => `exit 0`.
