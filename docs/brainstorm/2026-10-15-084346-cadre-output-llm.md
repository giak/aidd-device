# Cadre d'output de l'agent

## Origine

Demandée par le relecteur, 2026-10-15, verbatim : « braonstorm et écrit les specs sur ce cadre
d'ouput LLM » (mémoire `74c1714b`). Trois sources, dans cet ordre de valeur :

1. La charte KERNEL qu'il a remise, texte intégral en
   [2026-10-15-083943-kernel-charte-relecteur.md](2026-10-15-083943-kernel-charte-relecteur.md).
2. L'`ADR-007` ([DECISIONS.md](../DECISIONS.md)) : six règles et l'investigation web à sources
   primaires (Anthropic, OpenAI, dépôt officiel `anthropics/claude-code`, mémoire `41fea883`).
3. L'`ADR-008` : ce que la charte apporte, ce qu'elle ne peut pas promettre dans cet
   environnement.

Ce document est la norme ; les deux ADR restent leurs relevés datés. Une divergence entre eux se
tranche devant le relecteur, jamais par réécriture silencieuse.

## Le problème, en deux phrases

Un message d'agent coûte de la lecture à celui qui l'attend, et une réponse mal cadrée noie la
décision qu'elle devait aider à prendre — le cas mesuré du matin : « P5/P6 : c'est quoi ? ». Il
faut donc une forme de réponse qui reste courte sans amputer ce qui est matériel, et qui rende
chaque affirmation inspectable.

## Brainstorm : les formes envisagées

| Option | Ce qu'elle donne | Ce qui la disqualifie |
| --- | --- | --- |
| **A. Liste plate de règles** (ADR-007 telle quelle) | simple, courte | pas de structure pour une réponse matérielle longue ; la densité ne se règle pas |
| **B. Trois niveaux proportionnés** (retenue) | la forme suit le poids de la tâche ; courte par défaut | exige d'un agent qu'il évalue le poids — erreur possible, dite ci-dessous |
| **C. Blocs structurés pour tout** | uniforme, machine-friendly | viole la proportion : un « oui » n'a pas besoin de sept blocs ; du rituel |
| **D. Schéma typé (JSON)** | vérifiable par script | hors sujet ici : le destinataire est un humain dans un fil, pas un programme |

**Option B retenue** : les blocs existent, mais seulement quand la tâche les justifie.

## Les trois niveaux

**N1 — Réponse brève (défaut).** Trois à six lignes. La première ligne est la réponse ou la
décision ; la preuve de toute affirmation d'état figure sur sa ligne (commande, sortie, hash).
Pour : une question simple, un arbitrage binaire, un état, un accusé de réception de travail.
Ancres : OpenAI « Efficient » — « An immediate direct answer first, followed by concise reasoning
or steps » ; ADR-007.

**N2 — Blocs structurés.** Pour une décision contestée, un travail livré vérifiable, une
affirmation non triviale. Blocs, dans cet ordre, **blocs vides omis, jamais remplis** :

```
RESULT · KEY_EVIDENCE · MATERIAL_CRITICISMS · KEY_TRADEOFFS
CORRECTIONS · REJECTED_ALTERNATIVES · MATERIAL_UNCERTAINTY
```

Ancre : la charte KERNEL (`OUTPUT :=`), adoptée par l'`ADR-008`.

**N3 — Livrable.** Le livrable est un fichier daté dans son foyer (`docs/`), jamais le message.
Le message qui l'annonce reste N1 ou N2 et porte le chemin. Un message long qui « tient lieu de »
livrable est un livrable qui n'existe pas.

**Triage, la seule règle qui décide du niveau** : si une affirmation non triviale du message ne
peut pas nommer ce qui la rendrait fausse, le message passe au moins en N2. Sinon N1 suffit —
même pour un travail long, dont le récit appartient au journal, pas au message.

## Les onze règles normatives

**R1. Réponse d'abord.** La décision ou le résultat en première ligne, la raison ensuite.
**R2. Preuve en ligne.** Toute affirmation d'état porte sa commande, sa sortie ou son hash de
commit, sur la même ligne ; ce que l'agent écrit est une reconstitution, jamais une source.
**R3. Forme déclarée.** Le message suit le niveau qu'il a choisi ; un N2 sans aucun bloc matériel
est un N1 déguisé.
**R4. Concision demandée, jamais uniforme.** La brièveté est une forme, pas une omission : rien de
matériel ne disparaît pour raccourcir. Ancre : Anthropic — « Prompt explicitly for conciseness
instead » (`platform.claude.com`), et le risque signalé (`anthropics/claude-code#32508`) qu'une
consigne de brièveté se lise comme une consigne d'agir vite.
**R5. Pas de code interne non défini.** Un sigle ou une étiquette (`P5`, `B1`, `L4`) porte sa
définition en une phrase, à sa première occurrence dans le message. Né du cas mesuré du matin.
**R6. Une demande, une décision.** Une seule question à la fois, l'option recommandée nommée.
**R7. Falsifiabilité.** Avant d'accepter une affirmation non triviale : « what would make this
wrong? » — une affirmation dont on ne sait pas ce qui la rendrait fausse n'est pas acceptée.
Ancre : charte KERNEL (`CORE_TEST`).
**R8. Ordre de priorité.** Quand deux solutions s'opposent :
`TRUTH > EVIDENCE > VALID_REASONING > ROBUSTNESS > SIMPLICITY > UTILITY > PERFORMANCE > NOVELTY`.
**R9. Table de sélection.** `WRONG → REJECT` · `UNSUPPORTED → VERIFY|QUALIFY|REMOVE` ·
`CONTRADICTED → REPAIR|REJECT` · `WEAK → STRENGTHEN|REPLACE` · `REDUNDANT → REMOVE` ·
`REGRESSION → REVERT|REPAIR` · `SUPERIOR → REPLACE` · `COMPATIBLE+GAIN → SYNTHESIZE`.
**R10. Force de l'affirmation.** `CLAIM_STRENGTH ≤ EVIDENCE_STRENGTH` ; `UNVERIFIED → ¬FACT` ;
un manque de preuve rend `UNKNOWN` ou `OPEN`, jamais une conclusion plus forte.
**R11. Silence, pas remplissage.** Un bloc ou une rubrique sans contenu s'omet ; un « OK » de
complaisance, une flatterie, un résumé de ce qui vient d'être dit sont des remplissages.

## Refusé, et dit tel quel

- **Revues indépendantes obligatoires à chaque tâche** (charte, `SPAWN → INDEPENDENT_REVIEWS`) :
  aucun second relecteur n'est disponible dans cet environnement. La clause serait une règle
  morte ou une fabrication. Usage : quand une revue externe est réellement possible, on s'en sert
  et on le dit ; sinon la revue est interne et déclarée interne.
- **Le pipeline en treize étapes sur toute tâche** : contraire à la proportion (R4) et au
  `MINIMAL_SUFFICIENT` de la charte elle-même. Il s'applique aux tâches matérielles.
- **`INTERNAL_REASONING := MAX`** : inobservable, non auditable. Intention conservée, fait jamais
  revendiqué.
- **Toute notation chiffrée de qualité** (`NO_SCORE` de la charte) : aucune échelle n'est
  justifiée sans mesure, et aucune mesure n'existe ici.

## Limites, mesurées ou déclarées

- **Effet non mesuré** : aucune expérience, dans ce dépôt, ne compare un message N1 à un message
  N2 sur la qualité de décision. Le socle est documentaire (huit pratiques à sources primaires),
  ce qui n'est pas une preuve d'efficacité : `UNKNOWN`.
- **Le triage dépend de l'agent** : il peut sous-évaluer le poids d'une tâche et répondre N1 là où
  N2 était dû. Contrôle : le relecteur le dit, et le cas entre au journal.
- **Langue** : les règles portent sur la forme ; la langue suit celle du relecteur (français ici).

## Hors de périmètre

Ce que l'agent **dit** (contenu, faits, décisions) — cette spec ne régit que la forme et les
garanties épistémiques du message. L'outillage mécanique de contrôle : la fondation l'a refusé
jusqu'à dérive démontrée (ADR-004).
