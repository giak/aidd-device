## Decisions

| Decision                                                                                                                     | Why                                                                                                                                                                       |
| ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Destination = le dossier Source Data actuellement surligné** (exactement la cible du F5)                                  | Réutilise `copyFilesTo` tel quel (zéro backend) ; cohérent avec « les copie en un clic vers le bon sous-dossier » (README) ; une destination automatique par style serait une autre feature et recouvrirait l'aperçu `e` — le style est « la seule décision humaine » |
| **Le lot = tous les fichiers `nouveau` de l'index**, filtre ignoré                                                        | Le filtre est un filtre d'affichage (`state.filters`), l'index est la vérité ; le nombre exact est annoncé dans la modale avant toute écriture ; le comportement est explicité dans le README et le tooltip du bouton |
| **Confirmation obligatoire avant toute copie** (modale « fichier → destination », EPIC-051)                                   | `△DATA-SAFETY` : une copie de masse sur la musique de l'utilisateur est une opération de masse sur ses fichiers ; toutes les copies de l'app passent déjà par cette modale                              |
| **Zéro backend** : `POST /copy` est réutilisé tel quel (un fichier par appel)                                                | `/copy` crée déjà le dossier cible, écrit le style des deux côtés et ne peut pas écraser ; une route bulk dupliquerait cette logique et toucherait `app.py`, déjà earmelé pour un découpage (EPIC-055)              |
| **Pas de nouveau raccourci clavier en P1**                                                                                  | `S5` (scope strict) : la matrice clavier (78 cellules + 5 invariants) reste intacte ; le raccourci est listé en P2 dans l'EPIC-057                                              |
| **Le jumeau déjà présent dans le dossier cible est EXCLU du lot** ; le jumeau rangé ailleurs est conservé mais annoncé                | Exactement la règle de l'aperçu `e` (`buildRangementPlan` → `twinInDest`) ; copier le premier créerait un « nom-2.mp3 » via `_collision_dst` (doublon silencieux) ; le second est un choix de l'utilisateur, pas une erreur |
| **Le calcul du lot pré-calcule le journal et les noms source** (au lieu de `computeStatus` fichier par fichier)                | `computeStatus` recalcule `getJournalFiles(journal)` à chaque appel → O(fichiers × journal) ; un test de parité avec `computeStatus` verrouille l'équivalence de statut                            |
