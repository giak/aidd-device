# Spec — un repère de durée avant la session

> 2026-10-20, née à 22:34:24 (`date`). Elle ajoute un affichage à `porte`, sans ouvrir de session et sans
> changer le harnais. Décision de forme : l'[ADR-040](../../../DECISIONS.md) garde ses quatre blocs ; les
> deux lignes de durée entrent dans `▸ FIN`, elles ne créent pas un cinquième bloc.

## 1. Le besoin

Une personne qui lance un test sur un skill ne sait pas combien de temps prévoir. Les deux runs du cas
jouet donnent un ordre de grandeur, mais il n'est affiché nulle part au moment où la session s'ouvre.

## 2. Ce qui s'affiche, et quand

`orchestrer.mjs porte` imprime déjà, après la porte, le texte à coller et les réponses figées. Juste avant
son bloc `▸ FIN`, il ajoute deux lignes optionnelles dans ce même bloc :

```text
▸ FIN — porte passée, 2 réponse(s) figée(s) — la session s'ouvre maintenant, …
  pièces              : …
  durée estimée       : 10 à 20 min, ouverture et réponses comprises
  échantillon         : 2 runs ; mesuré 9 min 42 s à 15 min 06 s (session + harnais) ; modèles et gestes différents, aucun run humain
  à lire ensuite      : …
```

Le bloc fait cinq lignes, sous le plafond de six de l'ADR-040. Aucun autre bloc n'est ajouté et aucun
autre appel de `blocFin` ne porte ces deux lignes.

Pour un cas sans mesure, les deux lignes disent l'absence, jamais une durée inventée :

```text
  durée estimée       : aucune mesure pour ce cas
  échantillon         : 0 run ; aucune durée ne se promet
```

constante commentée d'`orchestrer.mjs`, pas dans un fichier de configuration : deux points ne justifient
pas une machinerie de lecture.

## 4. Les réserves, dites avec le chiffre

- `n = 2`, un seul cas, le cas jouet ;
- deux modèles et deux contextes différents ;
- **aucun run conduit par une personne devant l'interface** : les gestes du run du 2026-10-20 ont été
  faits par l'agent ;
- le harnais seul coûte environ **1 min 27 s** après la session, le reste est la session et les réponses.

Une durée n'est jamais une promesse. Le libellé le dit, et le cas sans mesure ne reçoit aucune fourchette.

## 6. Ce que cette spec ne fait pas

Elle ne mesure pas un nouveau run, ne modifie pas le harnais, ne change pas le verdict, et ne promet pas
une durée pour un autre cas. Elle ne crée pas de cinquième bloc : l'ADR-040 n'est pas amendé.
